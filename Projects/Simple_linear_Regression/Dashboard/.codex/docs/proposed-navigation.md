# Mapa funcional propuesto (sujeto a auditoría)

**Inicio:** titular basado en pregunta real + fuente/periodo + 1 conclusión estadística verificada.

**Explorar los datos (general):** contexto y muestra -> distribución y categorías -> relación de variables -> comparaciones (respetar peso/diseño) -> ¿qué aprendimos y qué no? Filtros solo si son honestos y útiles.

**Modelo de regresión (técnico):** pregunta/población -> operacionalización Y, X, unidades -> modelo poblacional/muestral -> estimadores/EE/IC/p -> supuestos y diagnósticos -> interpretación ceteris paribus -> causalidad y limitaciones -> reproducción/fuentes.

**Comunes:** cambio de tema, fuente, fecha/versión, glosario, estados loading/error/empty, accesibilidad y pie de metodología.
