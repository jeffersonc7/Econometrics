# Definition of Done / Checklist de aceptación

## Fuente y ciencia
- [ ] Inventario de `Data-Science` con rutas y celdas verificables.
- [ ] Dataset HF, commit, esquema y permisos comprobados; coincidencia con notebooks.
- [ ] Variables Y/X, población, unidad, periodo, filtros, NA y pesos documentados.
- [ ] Todo gráfico/KPI tiene fuente, unidad, N, ponderación y pregunta.
- [ ] Estimación reproducible, errores estándar correctos y límites causales explícitos.
- [ ] Pregunta del profesor, modelo poblacional/muestral, operacionalización, supuestos, EE y significancia cubiertos.

## Experiencia
- [ ] EDA comprensible sin conocimientos de econometría.
- [ ] Área regresión técnica, con fórmulas y diagnóstico fieles.
- [ ] UI enteramente en español y sin autenticación.
- [ ] Estética inspirada por capturas Cristal en claro/oscuro.
- [ ] Móvil, tablet, escritorio, teclado, foco, contraste, reduced-motion.
- [ ] Filtros y tooltips correctos, sin gráficos de adorno.
- [ ] Usuario entiende la fuente y fecha de actualización.

## Ingeniería
- [ ] API/archivos de agregados con contrato, tests y metadatos.
- [ ] Sin secretos ni datos personales en cliente/API pública.
- [ ] Sin cambios inadvertidos en `Data-Science`.
- [ ] `npm run build` y pruebas Python ejecutadas con resultados registrados.
- [ ] Setup local y despliegue documentados; despliegue pendiente de autorización.
