# Skill: Evidence First Data Visualization

Para cada visual define:
`question`, `audience`, `source`, `population`, `unit`, `filter`, `weight`, `n_unweighted`, `denominator`, `transform`, `chart`, `insight`, `limitation`.

Antes de aprobar: ¿responde la pregunta?, ¿tiene base estadística?, ¿los ejes y etiquetas no inducen a error?, ¿comparación con grupos de tamaños distintos es válida?, ¿es útil en móvil?, ¿complementa otra visual o la duplica?, ¿qué decisión informativa aporta? No usar treemaps/donut/radiales por novedad. Evitar precisión espuria, porcentajes sin denominador y defaults silenciosos. Para series incompletas, diferenciar ausente de cero.

Un `insight` no debe afirmar más de lo que soportan datos y modelo. Eliminar visual sin propósito.
