## Revalidación backend y CSS

Tras correcciones del orquestador se repitió el harness independiente: artefacto incompleto → 503 INVALID_DATA; salud con archivo corrupto → 503; salud con archivo válido → 200; ruta NUL → 404. Se revisó `contract.py` sin hallar discrepancias de cálculo ni exposición de microdatos. Los tres fallos de backend quedan cerrados.

CSS leído: las grillas se apilan a ≤700 px, las tablas tienen scroll local, los hashes permiten ruptura de línea, y tema y reduced-motion tienen reglas explícitas. Falta comprobar en navegador. Existe un riesgo concreto de ejes SVG: a 360 px el contenido de la tarjeta mide aproximadamente 282 px y el viewBox es 620; la fuente 17 del gráfico de ingreso se convierte en unos 7,7 px reales y las etiquetas largas pueden solaparse. También a 768 px las dos columnas estrechas vuelven pequeña la fuente 12. Se recomienda dimensionar los ejes según el contenedor y abreviar los ticks. Los botones Mediana/Promedio tienen 38/40 px de alto; se solicita subirlos a 44 px según instrucciones. Ambos hallazgos fueron enviados a frontend y al orquestador.

| ID | Severidad | Evidencia | Recomendación | Estado |

| UX-CHART02 | P3 | Conteo 0 de hora 17 dibuja barra 1 px por Math.max(h,1) | Para 0, altura 0; conservar categoría y tabla | Reportado a frontend |
| UX-TARGET01 | P2 | Botones Mediana/Promedio min-height 38/40 px | Aumentar mínimo a 44 px | Reportado a frontend |
| UX-TIME01 | P3 | La operacionalización de X no menciona últimos 12 meses | Añadir referencia de 3A antes de condicionar frecuencia diaria | Reportado a frontend |
